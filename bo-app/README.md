# Back Office app

Vue 3 + TypeScript portal for staff: review the queue of client change requests, compare the current and proposed payment method, and approve or reject.

```
npm install
npm run dev        # http://127.0.0.1:5174 (proxies /api to the backend on port 8080)
npx vitest run     # unit tests
npm run build      # type-check and production build
```

See the [main README](../README.md) for the full system, setup and design decisions.
