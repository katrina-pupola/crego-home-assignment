# Client app

Vue 3 + TypeScript portal for clients: register, confirm the email, add a bank card or bank account, request a change and follow its status.

```
npm install
npm run dev        # http://127.0.0.1:5173 (proxies /api to the backend on port 8080)
npx vitest run     # unit tests
npm run build      # type-check and production build
```

See the [main README](../README.md) for the full system, setup and design decisions.
